
# ClassPilot AI Backend

Backend API for the ClassPilot AI coaching management SaaS.

## Technology
- Node.js
- Express
- PostgreSQL
- Prisma ORM

## Current status
Initial Express server setup.

Database connection, authentication, authorization,
and business APIs are not implemented yet.

## Run locally

1. Install Node.js 20 or newer.
2. Run `npm install`.
3. Copy `.env.example` to `.env`.
4. Run `npm run dev`.
5. Open `http://localhost:3000/api/health`.

Never commit your real `.env` file.
